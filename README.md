# 🌶️ CHILLI-SHIELD

### See the disease before it sees your harvest.

CHILLI-SHIELD is an AI-assisted agricultural solution designed for the early visual detection of diseases and health conditions in chilli plants.

The system provides a preliminary AI-assisted visual risk assessment from chilli leaf images and helps farmers, students, researchers, and field workers identify potential plant health issues at an early stage.

> ⚠️ **Disclaimer:** CHILLI-SHIELD provides a preliminary AI-assisted visual risk assessment and is not a replacement for expert diagnosis or laboratory confirmation.

---

## 🎯 Key Features

- 🌿 AI-assisted chilli leaf image analysis
- 🔍 Preliminary disease risk assessment
- 📊 Simple and user-friendly dashboard
- 🌱 Support for multiple chilli leaf conditions
- 📱 Designed for practical agricultural use
- 🧑‍🌾 Farmer and field-worker friendly interface

---

## 🦠 Supported Conditions

The project uses a chilli leaf image dataset containing six categories:

- Bacterial Spot
- Cercospora
- Curl Virus
- Healthy Leaf
- Nutrition Deficiency
- Powdery Mildew
